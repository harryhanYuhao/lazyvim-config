# 💤 LazyVim

This config is my personal lazyvim config based on starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

I recommend to make different configurations of neovim independent by the alias: 

```bash
alias lazyvim=NVIM_APPNAME="lazyvim nvim"
```
